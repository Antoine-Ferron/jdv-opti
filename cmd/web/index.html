Les règles

Une plaine brûle 1 tour, une forêt 2. Ensuite la case reste trop chaude pour rebrûler, 2 ou 3 tours.

L’eau ne brûle jamais : le feu la contourne.

Une case ventée n’enflamme pas ce qui est derrière elle, et projette le feu deux cases sous le vent — le seul moyen de franchir une rivière.

Les bords se rejoignent : le feu ressort de l’autre côté.
